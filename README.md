# Spendly — Student Expense Manager

### Spend Smart. Live Better.

Spendly is a student-focused UI/UX design project created to promote better spending habits through a simple, modern, and student-friendly website experience.

## 🔗 Project Links

- **Live Website:** https://tranquil-seat-857687.framer.app/

- **Pomelli:** https://labs.google.com/u/0/pomelli/bdna

## 🎯 Project Objective

To create a clean and accessible website concept that helps students understand expenses and develop mindful spending habits.

- **Relume:** Sitemap and wireframe planning
- **Framer:** Website design and publishing
