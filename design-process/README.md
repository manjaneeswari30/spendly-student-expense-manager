# Spendly — Design Process

This folder documents the design workflow followed for the Spendly UI/UX project.

## Tools and Workflow

### 1. Pomelli — Branding
Used to explore the brand identity and create visual branding assets.

### 2. Relume — Sitemap
Used to plan the website structure and organize its pages.

### 3. Relume — Wireframes
Used to plan page layouts and content sections before website development.

### 4. Framer — Website
Used to build and publish the final website.
